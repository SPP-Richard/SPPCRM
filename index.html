Data folder (snapshots on disk)
Connect a folder on your computer (recommended: a OneDrive subfolder) and snapshots will be saved there as JSON files instead of in browser storage. This bypasses the ~5MB browser limit and gives you OneDrive cloud sync for free.
Daily snapshots
The app takes a silent snapshot of all your data on first load each day, plus before any wipe or restore. Last 7 snapshots kept. Use these to revert if something goes wrong.
Off-device backup & restore
Download backup saves a JSON file containing every project, sales rep, company note, BT code, tag and saved setting. Keep it somewhere safe (e.g. OneDrive). Restore from backup overwrites everything currently in the app with the contents of a backup file.

Inbox scan — settings
Admin only — choose which mailboxes are included in the bulk scan and control cost display tenant-wide
Mailboxes included in bulk scan
Tick the users whose inboxes the admin bulk scan should touch. Untick the rest to save cost. Non-ticked users can still run their own "scan my inbox" on demand.
Cost display
By default each user can hide the per-run cost indicator in their Scan panel. Turning this on forces it visible for everyone and disables each user's Hide button.
Email matching rules
Controls what the inbox scan does with each email. Categories are the strongest signal — emails tagged with a project category in Outlook are auto-imported (Tier 1). Keywords help spot new project enquiries. Ignore lists keep noise out.
Test inbox fetch (Phase 8v-2a)
Read N days of email from your Outlook via Microsoft Graph and show a summary of what the matching pipeline would do. Useful for validating the integration and previewing how your settings classify real emails before the full scan UI ships in 8v-2d.
